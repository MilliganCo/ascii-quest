# ASCII Quest

## Описание

Игровой frontend-прототип на TypeScript, Vite и Pixi.js с изометрической подачей, локальным сохранением прогресса и базовыми системами перемещения, боя и поведения врагов.

Несмотря на название, проект ближе не к классическому текстовому roguelike, а к стилизованной визуальной игре с компактным движком, собственной камерой, HUD и набором игровых систем на клиенте.

## Что есть в проекте

- запуск игры в браузере через Vite;
- изометрическая отрисовка мира;
- камера и управление перемещением;
- базовая боевая логика;
- поведение врагов;
- HUD и кнопки способностей;
- сохранение состояния в `localStorage`.

## Стек

- TypeScript
- Vite
- Pixi.js

## Запуск

1. Установите зависимости: `npm install`
2. Запустите dev-сервер: `npm run dev`
3. Для production-сборки используйте: `npm run build`
