# ASCII Quest — Design Document

**Дата:** 2025-02-27  
**Статус:** Утверждён

---

## 1. Обзор

Веб-игра **ASCII Quest** — action-adventure в открытом процедурном мире. Изометрическая 2.5D камера, рендер ASCII-символов как графических элементов. Оптимизация под мобильные устройства с управлением одной рукой.

**Стек:**
- PixiJS v8 (WebGL, fallback Canvas2D)
- TypeScript
- Vite
- HTML/CSS для UI поверх canvas

**Слои приложения:**
1. Рендер — PixiJS, изометрические координаты
2. Игровая логика — мир, сущности, бой, AI, процедурная генерация
3. Input — клавиатура + touch (slide-to-move, auto-attack)
4. UI — HUD, кнопки способностей (DOM поверх canvas)

**Структура проекта:**
```
src/
  engine/      # PixiJS, камера, изометрия
  game/        # мир, сущности, бой
  procedural/  # генерация карты, спавн
  ui/          # HUD, мобильные контролы
  assets/      # bitmap fonts, спрайты символов
```

## 2. Рендеринг ASCII в 2.5D (изометрия)

**Координаты:**
```
screenX = (worldX - worldY) * tileWidth/2
screenY = (worldX + worldY) * tileHeight/2
```

Тайл = один ASCII-символ. Высота тайла ~0.5 от ширины.

**Символы:** Bitmap font / текстура-атлас. Каждый спрайт — `PIXI.Sprite`. Цвет задаётся от типа сущности.

**Z-order:** земля → объекты → сущности (сортировка по worldY).

**Камера:** Container, слежение за игроком, lerp. Опционально pinch-to-zoom.

**Оптимизация:** Viewport culling, object pooling для спрайтов.

## 3. Цветовая схема

**Общий стиль:** приглушённая, низкая насыщенность, приятная глазу.

| Элемент | Цвет |
|---------|------|
| Трава | `#6b7b5c` |
| Камень | `#7a7a7a` |
| Вода | `#5a6b7a` |
| Деревья | `#4a5a4a` |
| Игрок | `#c9b896` |
| Акценты (HP и т.п.) | `#9a8a7a` |

**Враги (по опасности):** от красного до фиолетового
- Слабые: `#8b6b6b`, `#7a5a5a`
- Средние: `#7a5a7a`
- Опасные: `#5a4a6b`, `#4a3a5a` (фиолетовый — самый опасный)

## 4. Игровые системы

**Мир:** Chunk-based (например 32×32), бесконечный/крупный. Тайлы: `.` трава, `#` камень, `~` вода, `T` деревья.

**Процедурная генерация:** Noise (Simplex/Perlin) → биомы. Random placement деревьев, врагов, лута. Seed для воспроизводимости.

**Сущности:** Игрок `@`, враги (`g`, `o`, `O` и т.д.). Компоненты: позиция, HP, урон, скорость, AI.

**Бой:** Real-time. Автоатака ближайшего врага, когда игрок стоит. Cooldown. Простой AI врагов.

**Инвентарь:** Минимальный — оружие/броня, 2–3 слота, heal consumables.

---

## 5. Управление и мобильный UX

**Slide-to-move (touch):** Свайп задаёт направление. Игрок идёт пока не остановится или новый свайп. Короткий тап = стоп. Вся область экрана для управления.

**Атака (archer.io-style):** В движении — не атакует. Стоит — автоатака ближайшего врага в радиусе. Без кнопки атаки.

**Способности:** 1–3 кнопки в углу (Q, E, R на десктопе). Cooldown, иконки.

**Десктоп:** WASD или клик для движения. Остановка = автоатака. Способности — клавиши.

**UI:** Кнопки способностей — один угол. HUD — противоположный. Максимум свободного пространства для мира.

---

## 6. Data flow и техдетали

**GameState:** Единый источник. Позиция, HP, инвентарь, чанки, сущности, cooldowns.

**Поток:** Input → InputHandler → GameLogic → GameState. Renderer читает GameState → PixiJS.

**Сохранение (опционально MVP):** localStorage при закрытии/visibility change. Загрузка при старте.

**Ошибки:** WebGL fallback на Canvas2D. Защита от некорректного input. Пауза при потере фокуса.

**Производительность:** Chunk loading/unloading. Throttle resize на мобильных.
